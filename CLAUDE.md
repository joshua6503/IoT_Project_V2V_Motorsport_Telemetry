# CLAUDE.md — V2V Motorsport Telemetry

Context for any Claude session working in this repo.

## Project

School IoT project and portfolio piece (automotive embedded). Each competition
vehicle is a node that publishes telemetry over **Wi-Fi/MQTT** and shares critical
events (hard brake, obstacle, over-temperature) with other vehicles over **BLE (V2V)**;
the receiver drives an actuator (LED/shift light, buzzer, haptic, relay).

- Node A: NXP FRDM-RW612, MCUXpresso IDE + SDK. Main node.
- Node B: ESP32 classic, Arduino IDE. Test/support node.
- Gateway: Mosquitto + Node-RED in Docker (local).
- Team: Joshua A. Chávez Montero, Mario A. Mireles González, Kevin Rincones Partida, Jair Santana Renteria.
- Environment: Windows + PowerShell. Give PowerShell commands, not bash.

## Golden rules

1. **Contracts in `interfaces/` rule.** A protocol change is made in `interfaces/`
   first, then in code. Never edit `firmware/esp32-node/esp32-node/src/v2v_protocol.h`:
   it is generated by `tools/sync_protocol.py`.
2. **Every relevant decision gets an ADR** in `docs/adr/` (copy `0000-template.md`)
   plus a dated line in `docs/project-notes.md`.
3. **The NXP SDK is never committed.** No `fsl_*`, `device/`, `CMSIS/`, `middleware/`.
4. **Pure logic goes in `firmware/common/`, with a unit test** in `tests/unit/`.
   No SDK, RTOS or I/O there.
5. **Do not invent pins or specs.** Unknowns stay `TBD` in `hardware/` and get asked.
   Unmeasured performance numbers are marked "(target, to validate)".
6. `#include "fsl_*.h"` only in `firmware/rw612-node/board/`.

## Arduino include limitation

Arduino IDE compiles only files inside the sketch folder (and its `src/`), so a
relative include into `interfaces/` fails. `tools/sync_protocol.py` copies
`interfaces/c/v2v_protocol.h` into `firmware/esp32-node/esp32-node/src/` with an
"AUTO-GENERATED COPY" banner. CI regenerates it and fails on any diff.

## Conventions

- Languages: code, comments, README, ADRs, contracts and technical docs in **English**.
  School deliverables in **Spanish**, under `docs/deliverables/`.
- Commits: Conventional Commits with optional scope —
  `feat(rw612): ...`, `fix(esp32): ...`, `docs(adr): ...`, `test: ...`, `chore: ...`, `refactor: ...`.
- Branches: `main` (stable), `feat/...`, `fix/...`, `docs/...`.
- C: `snake_case` files and symbols; module prefixes `v2v_`, `tlm_`, `alert_`.
- Secrets: `firmware/esp32-node/esp32-node/config.h` is git-ignored; template is `config.example.h`.
